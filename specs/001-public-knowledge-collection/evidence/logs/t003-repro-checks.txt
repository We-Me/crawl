## 2. .env 显式加载与配置解析（project-startup.md 起步顺序第 5 步）

UV_CACHE_DIR=/tmp/crawl-uv-cache uv run --locked --no-python-downloads --env-file .env \
  python -c "import os; print('CRAWL_ENV=', os.environ.get('CRAWL_ENV')); print('CRAWL_DATA_DIR=', os.environ.get('CRAWL_DATA_DIR'))"
# CRAWL_ENV= development
# CRAWL_DATA_DIR= ./data

UV_CACHE_DIR=/tmp/crawl-uv-cache uv run --locked --no-python-downloads --env-file .env \
  python -c "from crawler.config.settings import load_settings; s = load_settings(); print('resolved:', s.mode, s.data_dir)"
# resolved: development /home/zhou/workspaces/crawl/data
# 结论：uv 显式加载的 .env 使变量进入 os.environ；相对 ./data 按工程根解析（非当前工作目录），
