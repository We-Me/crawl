## 受限来源：工程诊断与外部决定分开

- 明确 robots 禁止、条款拒绝、登录/验证码：停止对应路径。记录已有证据；需要许可时给出对象和允许方式需求，不把用户批准当作网站许可。没有条件变化不反复探测。
- TLS/证书或连接问题：目前 IN-04/07/08/09 的记录不足以证明网站禁止访问。先核对目标 WSL 时钟、CA、代理配置与错误链；与已有工具结果作一次针对性对照。只采用可验证的可信证书来源，不使用 verify=False 或 curl -k。需要系统安装或组织 CA 时说明具体原因与权限；不默认换 Python、停用证书校验或扩大采集。
- HTTP 508（CN-05/06/07）：记录 HTTP 现象，不能凭状态码认定唯一原因或永久禁止；已有多轮复现，无新线索先复用证据。查出可行动配置/站点信息后再有限验证。
- 域名别名（IN-03、CN-01 旧域）：在已选来源内可以核实官方重定向/站内链接、归属及对应规则。证据充分时按精确域名配置并留证；这属于 Q12 的工程落实，不要求再次选择 18 来源。归属不明、主体变化或涉及新访问许可时只暂停相关域名，不使用广泛通配。
- CN-04 等前端列表：页面公开声明且合法可用的接口可以调查和适配；没有静态链接不等于只能等用户决策。不得猜测私有端点或绕过已拒绝路径；已有允许替代入口先推进。

## raw 门槛与覆盖表

每个有正文的成功响应应可核对 raw 路径与字节哈希。304 无新响应正文时引用既有实体/状态并明确记录，不伪造新原件；robots 等控制请求保留访问决策证据，与业务资源分母区分。发现页归档不强制生成 normalized 文档。

来源报告至少分开记录：入口/发现状态、已遍历范围与停止原因、已发现主目标、成功/失败/跳过/待处理主目标、附件对应计数、raw 留存校验、已产出文档块追溯。如增加运行指标字段，在 data-model 与 structure-comparison 登记；不改变原文基础 JSONL 的含义。

- 已取得业务响应的原件与账本必须完整可对账；正文处理失败不影响 raw 留存。
- 已产出 documents/blocks 100% 可追溯；零文档为不适用，不能空分母判通过。
- 仅已知集合可以给完整率；发现提前截断时全窗口总量是未知，不填成 0 或拿当前成功数作“全站分母”。
- 失败历史不清零删除；成功恢复保留前后关联。仍失败、仍受限或仍有待处理时，明确记录该窗口未完成。
- “有限样本可用”“声明窗口采集完成”“正式总验收通过”是三个状态。开发阶段目标是可验证推进的 raw 链路，不把窗口选择升级成无需上限的大运行。
