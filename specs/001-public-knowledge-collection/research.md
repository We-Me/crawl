## ADR-001 采集与领域职责可分离

问题：S1 明确排除派生切片与索引，S2 则有七类实体、切片和领域检索方向。候选：按两个相连职责划分模块，通过原件/文档/块及来源关系交接。理由：保留两侧要求，又能将实施边界显式交给 Q01。替代方案是全部作为爬虫职责，或只留采集而删除领域要求；前者会把未定范围合并，后者丢失 S2 依据。影响：T020—T025 为条件任务，不能自动宣称是已确认后续阶段。

## ADR-002 文档显式关联抓取

问题：S1 有 crawl_id，但 document 字段表没有抓取关联，目标又要求完整追溯。候选：document 增加 crawl_ids 数组，可关联 HTML 多页、API 多响应或多次抓取。raw_path 仍按原表保留主原件，其他相关原件通过 manifest 查出。替代方案：只用 URL/哈希推导，可能在重定向、多语言和重复抓取中歧义。影响：Q03，新增字段在 schema 标为候选扩展，只有定稿的实现契约可强制要求。

## ADR-003 区分原件与内容哈希

问题：S1 manifest.sha256 明确为原件，document.sha256 允许正文或原文件，S2 content_hash 未给同一算法定义。候选：document.sha256 对主原件字节，新增 content_hash 对保序全文的确定性 UTF-8 表示；只归一换行及约定的 Unicode 表示，不为了去重删除条款、数字或多语差别。规范化规则版本必须跟随处理配置保存。替代方案：复用同名 sha256 表示不同对象会导致误关联。影响：Q04；本次基础 schema 仍保留 S1 对 document.sha256 的两种解释，不以候选覆盖原文。

## ADR-004 保留资源身份并可共享物理原件

问题：S1 要求正文与重复附件原件都保留，又要求相同 SHA-256 不保存无意义副本。候选：每个资源和获取记录保留独立身份，同字节共享一份持久可达原件，文档关系反映重复。替代方案：每身份复制文件，语义简单但占空间；只留单记录会丢来源。影响：Q05，需明确“保留两者原件”是否接受共享同字节文件；设计未获选择前不得进行破坏性去重。

## ADR-005 缺失元数据与结构数据表达

问题：详情页正文要求与字段表强度不一，纯表格/API full_text 语义未完整定义。候选：保留原表层级；缺失建议字段可省略并记录原因；无法完成必填正文的结果为 partial 或失败，不能伪造文本。结构数据完整保存在 structured_data，文本视图采用原单元格顺序和原始值，不用摘要。替代方案：把所有字段提升为必填会制造无来源值。影响：Q06/Q08；独立 records 文件和多记录分页契约尚待确定。

## ADR-006 文件接口优先

问题：输入规定文件成果但没有 HTTP 服务、用户界面或数据库接口。候选：交付仍以原格式文件和 JSONL 作为外部契约，内部接口按逻辑函数说明；不创建与需求无关的 REST API。替代方案：默认 Web 平台会扩大范围。影响：Q14；运行状态存储可在规模明确后选择。

## ADR-007 来源字段独立管理

问题：country/source_country、authority_level/source_authority 和 stance_default/stance 处于不同对象，原文未给完整继承规则。候选：显式映射并记录出处；机构权威描述与证据等级分开；文档有证据时可覆盖来源默认立场。替代方案：根据站点国别自动推断所有文档立场，无法准确描述双方联合文件和转载。影响：Q10，领域字段强制等级按 S2 适用对象确定。

## Python 开发约束

用户已明确使用 Python 和 uv，优先 3.9；先构建完整环境，再根据失败证据逐个次版本保守升级，框架及依赖组合待选。TD-01/TD-02 的选择与证据记录见 tech-stack.md；Agent 可在授权范围内先比较、试验并记录工程决定，不把本机运行环境或文档校验最低版本当成业务项目版本。

## 实施前技术验证

T002 用少量固定样本验证：文本 PDF 与扫描 PDF 区分、DOC/XLS 旧格式是否支持、Unicode 三语是否保真、表格合并单元格和脚注是否可定位、HTTP 超时和重试是否可控。记录所选版本、目标操作系统、样本差异和已知限制。当前没有这些试验结果，不能把文档样例检查写成技术栈验证。

## ADR-008 源码布局与运行数据根

状态：工程约束已记录，运行实现未验证。依据：2026-09-11 用户要求代码放 src/、开发结果与 src/ 同级、正式运行目录可配置。选择 src/crawler/ 与开发 data/，进程环境变量作为配置接口，uv 显式加载 .env，生产指定绝对数据根；不额外增加 dotenv 依赖。调研比较、官方资料、路径语义及验收见 [项目起步说明](project-startup.md)。影响 DEV-008、Q14 的部分决定以及 T003/T004/T018/T019；不关闭其余业务待决项。
