## 最小实现约束

### 分块抽象与 dummy

使用标准库 abc 定义可替换分块接口，最小实现有真实确定性行为，不是返回空列表或伪造成功。复用现有 ParsedBlock、结构解析与 ID/顺序规则，不删除已工作的 Office/PDF/HTML 解析能力。

标题、段落、列表项、表格等仍按独立结构块保留。div 空行规则只处理尚未被这些结构节点覆盖的正文文本，保留 DOM 顺序与定位，避免父 div 与子节点重复输出。不得对原始 HTML 源码的排版缩进直接 split；应先按 DOM 获取文本和显式换行，再按一个或多个空白行分隔。单个换行不自动视为空行，连续 br 可形成空行；空白字符归一化不得提前抹去分隔信号。表格、列表不因空行规则被压平成普通文本；嵌套 div 不重复消费。上述为本次工程落实规则，需固定样例验证，不冒充原文既定算法。

不增加 token 上限、语义合并、重叠或模型依赖。dummy 的方法与版本要可识别，优先使用现有 extraction_method 和运行记录；若需新增字段，先列差异，不修改冻结字段语义。未实现的后处理明确标记 deferred/dummy，不伪造 full_text、元数据或 parse_status=ok。

### 按站发现抽象

SourceAdapter 保留为配置 dataclass；61e34d8 已新增 DiscoveryStrategy 抽象与实现，不能将配置类与策略接口混同。以下约束继续适用于已有实现演进。保留既有配置兼容性，在发现层建立抽象接口与具体实现，复用共享 HttpClient、robots、限速、预算和跳转边界。按来源选择适配实现；共同策略可共享实现，禁止复制 18 份空壳冒充完成。未实现来源要可识别，不能用 dummy 链接或空结果记成功。

### 运行时起始时间

61e34d8 已实现 --start-date YYYY-MM-DD，以内容发布日期为包含式下界，抓取日期不能冒充发布日期；该参数名和语义为工程落实方案，实现时同步帮助与运行说明。站点支持查询时间时先利用该能力，再核对页面日期。日期未知或解析失败不得静默排除，应保留候选与原因；附件继承母页采集上下文，不能因自身无日期被漏掉。

仅在证实结果按时间单调且已覆盖置顶/缺日期等例外时允许提前停止翻页，不能遇到一篇旧文章就停止。执行记录保留起始日、来源、日期判断、跳过理由及预算停止原因；恢复任务保留原运行范围，不能把新窗口混入旧任务。近期测试可显式选择例如运行日前 7 天的窗口并记下实际日期；不将该测试窗口设成业务历史默认，不因缺少上界自动无预算回溯。

## raw 质量与验收边界

S1 §13 原文为“documents/blocks 100% 可回到 source_url、raw_path 和 crawl_manifest”，并要求“所有成功抓取的网页/附件均保留原格式”。本次用户进一步明确 raw 优先。分别验收：
- 成功获取的业务页面、正文分页、正文 API 与附件具有对应原件和账本；落盘原件字节哈希一致、路径可达、不越界，不能以格式化/清洗结果替代原件。
- 解析或后处理失败不得使已成功获取的原件丢失；失败、跳过、访问拒绝和预算停止分别记账，重试不覆盖历史事实。
- 已产出的 documents/blocks 仍必须 100% 可追溯；零文档时该项记不适用，不以空分母报告全部通过。
- 在声明的来源、时间和可访问范围内核对目标发现、分页/附件完整性；分别报告发现数、成功原件、失败、范围外跳过、限制及待处理项。哈希一致仅证明留存一致，不能证明发现了全站全部内容。
- 被拒绝或不可访问的来源记受限/未完成，零结果需有依据，18 个来源均有记录不等于 18 个来源通过。

正文精细抽取、OCR 准确率、语义去重等后处理质量仍保留原需求，当前 deferred；不为了 dummy 删除已有测试或放宽 raw/追溯要求。质量报告须区分本轮 raw 门槛与历史全量验收，不能通过改名消除未通过项。
